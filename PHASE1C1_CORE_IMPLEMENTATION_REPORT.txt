5. Authoritative data flow

Curve authority:
active RegressionSet -> ordered R/G/B RegressionChannelModel snapshot ->
CalibrationCurveView tuple.

Only slope, intercept, r_squared, valid_min, valid_max, and unavailable_status
from the active RegressionSet are copied into curve views. No formulas mapping,
XLSX, GUI value, worker, model, or reconstructed regression is consulted.

Calibration point authority:
caller-provided successful regression samples -> immutable CalibrationSample
snapshot -> included=True only -> per-channel CalibrationPoint tuples.

Detection point authority:
BatchState -> completed ImageItem values -> ImageItem.samples -> SampleResult ->
per-mode DetectionPlotPoint tuple.

Coordinates are fixed as R=(con_r, red), G=(con_g, green), and
B=(con_b, blue). no_in_image and batch_no are copied without assignment or
recalculation. selected_image_order alone controls is_current_image.

The output holds only frozen dataclasses, primitive values, enum values, and
nested tuples. It retains no BatchState, ImageItem, SampleResult, list, or dict
reference.

6. Revision gate results

CALIBRATION_REVISION_MATCH:
- included calibration points are projected into the selected curves.

CALIBRATION_REVISION_MISMATCH:
- active RegressionSet curves remain available;
- calibration point tuples are empty;
- calibration_points_stale=True.

DETECTION_REVISION_MATCH:
- completed images' formal SampleResult values are projected.

DETECTION_REVISION_MISMATCH:
- active RegressionSet curves remain available;
- detection_points is empty;
- detection_points_stale=True;
- no old concentration is recalculated.

NO_BATCH_STATE:
- detection revision is None;
- detection_points is empty;
- detection_points_stale=False.

7. Unavailable and non-finite point results

Plottable and preserved without reclassification:
- IN_RANGE
- BELOW_RANGE
- ABOVE_RANGE
- RANGE_UNAVAILABLE

Rejected independently per channel:
- missing concentration or intensity
- NaN or Infinity
- INVALID_SLOPE
- CALCULATION_FAILED
- every other non-plottable status

One invalid channel does not suppress valid sibling channels from the same
SampleResult.
