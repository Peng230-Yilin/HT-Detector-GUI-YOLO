4. Linear Plot Channel authority and menu

The only runtime authority is:

self._linear_plot_channel_mode

Accepted values are exactly R, G, B, and RGB. At DetectMain construction,
load_effective_settings(apply_to_module=False) is read once and its R/G/B
color_channel is copied as an initialization snapshot. Any other value or read
failure falls back to B. No Linear Plot mode is persisted.

The Detection setting settings["color_channel"] is never written by the plot
mode setter. Later Interface changes do not update Linear Plot mode, and later
Linear Plot changes do not update the Detection setting.

detectionwindow.py dynamically adds this hierarchy to the existing Linear menu:

Edit -> Linear -> Plot Channel -> R / G / B / RGB

The four QActions are checkable and belong to one exclusive QActionGroup. Their
checked state is a blocked-signal mirror synchronized by DetectMain; QAction

UI files were not modified.

5. Projection integration and revision gates

The production data flow is:

self._regression_session_state.active_regression_set
+ revision-matched _regression_result["samples"]
+ self._batch_controller.state
+ self._detection_selected_key[1] after run-token validation
+ self._linear_plot_channel_mode
-> build_linear_plot_projection(...)
-> LinearPlotProjection
-> render_linear_plot(self.ax, projection)
-> existing canvas.draw()

Plot formula fields are not read from _regression_result["formulas"]. Curves are
therefore sourced only from the active RegressionSet through the Phase 1C1 core.

CALIBRATION_REVISION_GATE:
- the payload must contain a formal RegressionSet;
- its revision must equal the active RegressionSet revision;
- only then are the payload samples supplied to the projection core;
- missing or mismatched payload identity supplies no calibration samples;
- the active curves remain available.

DETECTION_REVISION_GATE:
- BatchDetectionController.state is passed directly to the Phase 1C1 core;
- SampleResult is the only Detection point source;
- Phase 1C1 suppresses all points and marks them stale on revision mismatch;
- no concentration is recalculated and no numbering is reassigned.

SELECTED_IMAGE_ORDER_SOURCE:
- only the formal three-part _detection_selected_key is consulted;
- its run token must match BatchDetectionController.run_token;
- only key element 1 supplies image_order;
- current_image, current processing index, file name, path, combobox text, and
  table selection are not fallback authorities.
