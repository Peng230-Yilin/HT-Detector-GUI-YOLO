4. Authority chain and implementation

The only detection plotting authority is:
BatchState -> ImageItem -> SampleResult -> LinearPlotProjection ->
linear_plot_renderer.

SampleResult remains authoritative for con_r/con_g/con_b,
status_r/status_g/status_b, red/green/blue, no_in_image, and batch_no.
BatchDetectionController stamps detection_run_token only after the complete
existing callback identity gate accepts the payload. Untrusted payload copies
of detection_run_token are discarded. SampleResult.as_dict does not export the
internal run token.

BatchState stores the current accepted controller run token as a scalar.
No second counter was added. begin() clears old samples immediately, advances
the existing controller token, and makes old-run projections fail closed.
Stale, duplicate, and failed callbacks cannot restore prior points.

LinearPlotProjection remains a frozen dataclass with tuple containers and
copies only scalar values. DetectionPlotPoint now copies run_token and alpha.
It retains no BatchState, ImageItem, SampleResult, controller, or GUI reference.
A RegressionSet revision mismatch still suppresses detection points.

Continuous numbering:
- all accepted images from the current run are projected;
- selected image marker/annotation alpha=1.0;
- other current-run image marker/annotation alpha=0.30;
- selection changes only rebuilt scalar projection emphasis;
- stored coordinates, statuses, numbers, and SampleResult values are unchanged.

Per-image numbering:
- only the selected ImageItem is projected;
- switching selection rebuilds from that ImageItem.samples;
- no other image point or duplicate per-image number is retained.

5. Point, annotation, fit, and legend semantics

Normal finite points:
- R/G/B use red/green/blue diamonds;
- annotations use the same channel color;
- RANGE_UNAVAILABLE with a finite concentration uses the same normal diamond;
- non-finite or non-plottable statuses do not create a point.

Formal out-of-range points:
- BELOW_RANGE and ABOVE_RANGE only;
- R=#8B0000, G=#006400, B=#00008B;
- marker=x and annotation uses the same dark channel color;
- renderer never recomputes or overrides status.

RGB:
- every drawable channel point is retained;
- one annotation per unique sample;
- if any channel is out of range, annotation anchors to the first
  out-of-range channel in R/G/B order; otherwise it anchors to the first
  drawable R/G/B point.

Fit:
- the active RegressionSet valid range is a solid channel-colored segment;
- BELOW_RANGE extends only from range_min to the minimum visible formal
  below-range concentration with a dashed segment;
- ABOVE_RANGE extends only from range_max to the maximum visible formal
  above-range concentration with a dashed segment;
- both sides are independent;
- RANGE_UNAVAILABLE creates no dashed segment;
- y values use the unchanged slope/intercept scalars.

RGB summary legend:
- no detection points: no legend call;
- detection points: one #666666 diamond, Detected (n=N);
- formal out-of-range sample present: one #666666 x,
  Out of range (n=M);
- N and M are unique visible sample counts, never channel-point counts;
- no R/G/B, Standards, equation, or R² RGB legend entry;
- frameon=False, ncol=1 or 2, fontsize=9;
- title y=1.18, legend upper anchor y=1.08, axes top=0.80;
- title, summary band, and data band are separated and saved through the
  unchanged shared renderer/print_png path.

Single-channel:
- Standards, compact equation/R², Detected, and conditional Out of range
  entries are retained;
- actual channel colors and marker semantics are used;
- slope/intercept 4 significant digits and R² 3 decimals are unchanged.
